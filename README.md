# CheckApp 🍎🧪

CheckApp — это мобильное приложение для мгновенного анализа состава продуктов. Помогает расшифровать пищевые добавки (E-коды) и узнать их влияние на здоровье прямо в магазине.

## ✨ Основные возможности

*   📸 Распознавание по фото: Просто сфотографируйте состав на упаковке, и приложение само найдет все добавки.
*   ⌨️ Анализ введенных компонентов: Введите список E-кодов вручную через запятую для быстрой проверки.
*   🔍 Поиск по базе данных: Удобный поиск по названиям и номерам добавок с подробным описанием каждой.
*   🌐 100% Offline: Вся база данных хранится на устройстве — интернет в магазине не понадобится.

## 🛠 Технологии

*   Язык: Kotlin
*   База данных: Room (SQLite)
*   Распознавание текста: Google ML Kit
